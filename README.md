# Midjourney

## Entorno de Edición (IDE)
- **VS Code** (Estándar general)
- **Jupyter Notebooks** (Para investigación de modelos de IA)

## Ecosistema de Navegación
- **Google Chrome** (Pruebas de rendimiento web)
- **Discord Desktop App** (Entorno nativo de su bot principal)

## Gestión de Versiones
- **Git**
- **GitHub** (Alojamiento de repositorios y forks de optimización)

## Diseño UI/UX
- **Figma** (Prototipado de interfaz web Alpha)
- **Midjourney** (Generación de assets gráficos propios - Dogfooding)

## Lenguajes y Herramientas Base
- **Python** (Backend de IA y entrenamiento)
- **TypeScript** (Frontend de la web Alpha)
- **React & Next.js** (Frameworks para la interfaz web)
- **Google Cloud TPUs** (Infraestructura de supercomputación exclusiva)
